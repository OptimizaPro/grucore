# Construction & Remodeling Finance — Guatemala (AI Agent Skill)

## Contents
- `SKILL.md`: entry point, scope, invariants, agent workflow, definition of done.
- `references/chart-of-accounts.md`: proposed chart of accounts.
- `references/formulas-and-reports.md`: P&L, KPIs, period views, and formulas.
- `references/costing-and-analytics.md`: analytical dimensions and operational workflows.
- `references/guatemala-compliance.md`: Guatemala-specific compliance guardrails.
- `references/acceptance-tests.md`: calculation, accounting, inventory, security, and reporting tests.

## Installation
Copy the complete `construction-remodeling-finance-skill` folder into the skills directory supported by your AI coding agent. Keep `SKILL.md` at the skill root and preserve the `references/` folder.

If your agent platform requires a different manifest or frontmatter schema, adapt only the metadata format while preserving the domain instructions and reference files.

## Important
This is a management/domain design, not a statutory Guatemalan chart of accounts or legal/tax opinion. Have the company’s accountant map accounts and approve current tax configuration before production.
