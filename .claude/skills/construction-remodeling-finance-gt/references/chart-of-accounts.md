The following coding is a starting hierarchy. Parent accounts should be non-posting where the ERP supports this; posting accounts should be leaf accounts. The exact code length and account nature should follow the company’s approved catalog.

## Account mapping rules

- Do not assume the class numbering above is statutory or mandatory.
- Map every posting account to the approved general ledger account catalog.
- Define normal balance, financial statement group, tax mapping if applicable, allowed dimensions, and posting restrictions for every account.
- Parent accounts should not receive journal postings if the ERP supports this control.
- Revenue, VAT, customer advances, and receivables must be separate concepts.
- Inventory purchases, inventory consumption, supplier invoices, and supplier payments must not create duplicate expense.
- Fixed-asset purchases must follow the capitalization policy; depreciation must be posted once.
- An analytical equipment-use charge is not an additional GL expense unless the accounting design explicitly posts a corresponding allocation and reconciles it to the cost pool.
